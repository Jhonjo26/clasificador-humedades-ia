# 🛠️ Sistema Automatizado de Clasificación de Humedades con Python

Este proyecto implementa una solución de automatización lógica diseñada específicamente para el sector de la construcción y refacciones edilicias. El sistema optimiza el tiempo de respuesta técnica clasificando automáticamente las solicitudes de los clientes según la descripción de sus problemas estructurales.

## 🚀 Problema que Resuelve
En empresas de soluciones de humedad, los técnicos pierden horas valiosas filtrando manualmente mensajes confusos de clientes. Este script procesa el texto de entrada, identifica palabras clave técnicas y asigna una categoría de reparación inmediata.

## 📊 Arquitectura del Flujo Logístico
* **Entrada:** Descripción textual del problema enviada por el cliente.
* **Procesamiento:** Algoritmo de normalización de texto y análisis de palabras clave en Python.
* **Salida:** Clasificación del tipo de patología y recomendación del tratamiento técnico requerido.

## 🔍 Categorías Soportadas actualmente
1. **Filtración por Cubierta:** Problemas originados en techos o terrazas que requieren impermeabilización líquida o membranas.
2. **Humedad por Capilaridad:** Problemas provenientes de cimientos que requieren inyección de resinas hidrófugas.
3. **Humedad por Condensación:** Deficiencias de ventilación que requieren puentes térmicos o placas secantes.
